Lock a resource with a secret hand gesture.

In-browser simulator of an embedded security device I built at NYU using an ATmega328p and an MPU6050 accelerometer. It runs the same finite-state machine as the firmware: record a 3-move motion sequence, then replay it to flip the LED on. Wrong gesture? Stays locked.

Finite-State Machine

The firmware models the lock as an FSM: RECORD → ARMED → UNLOCKING → OPEN. The same FSM runs in this browser demo.

📐

Direction Detection

Raw accelerometer X/Y/Z is thresholded into one of six discrete directions, with a 500 ms debounce so a single flick maps to one symbol.

🔒

Hardware Output

On a correct sequence, GPIO pin 13 is driven HIGH for 3 seconds — the unlock signal that could drive a relay, solenoid, or door strike.
